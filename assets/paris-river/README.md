# Paris River Level Analysis

Independent portfolio project by Nazmus Sakib. November 2026.

Live case study: https://nsakiblive.github.io/case-paris-river.html

The package contains the original supplied paris_flood_dataset.csv, analysis_data.csv (all 53,687 rows), prepare_data.py, quality_report.json, station_coverage.csv, field_dictionary.csv, station_selection_rules.md and the methodology PDF.

Rebuild: python prepare_data.py paris_flood_dataset.csv output_directory

The script uses the Python standard library. No source value is corrected or removed. Source hash, audit controls and exclusions are documented. The website calculates descriptive charts client-side, one station at a time.

Original-source verification and station datum comparability remain pending. This is independent supplied-file analysis, not an official warning service. No merged long-term trend, causal climate finding or separate flood-event count is claimed. Source license provenance has not been independently verified.
