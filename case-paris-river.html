01 / START WITH A QUESTION

What can these records
tell us about the river?

A high reading can draw attention on its own. Understanding it takes more context.

What happened before the peak? How long did the water stay elevated? Which station recorded it, and was the observation validated?

This project examines those questions through the historical series. It also makes visible the decisions needed before the records can be compared.

07 / WHAT DOES THE ALERT FIELD MEAN?

Count observations
carefully.

64

Observations are marked flood_alert = True. These are flagged records, not necessarily 64 separate flood events.

Consecutive observations may belong to one high-water episode. Overlapping stations may also record the same date.

In this extract, every alert flag matches water level greater than 6,000 mm. That relationship does not establish that the label represents an official warning issued at the time.

This project examines historical records. It is not an operational flood-warning system.

08 / DATA & METHOD

Make the choices
visible.

Original observations are preserved. Missing dates are not zero. Any exclusion is documented.

About the supplied data

The supplied Paris river-level file contains station codes, recording dates, water levels, production information, validation status and quality assessments. The data covers 2 January 1900 to 24 August 2026. The original file is included in the downloadable package.

Station-selection rules

No stations are merged. Each chart selection uses one station. Annual maxima count only observations matching the year, quality and validation filters. Coverage is shown against the full calendar year, including partial first and final years. Event views use an explicitly named station and period.

Units, gaps and monthly distributions

Millimetres are divided by 1,000 to display metres. No datum adjustment, interpolation or imputation is applied. Missing event dates break the line. Monthly medians and interquartile ranges pool observations only within the selected station and filters. Percentiles use linear interpolation between sorted observations.

The flagged extreme

The exclusion rule identifies station F700000102 on 24 July 2026 with a recorded value of 942,000 mm. The original record and value remain in the downloadable source and analysis CSV. Its quality label is unqualified and its validation status is raw.

Verification status and interpretation limits

Supplied-file checks and descriptive chart calculations are complete. Original-source verification and station reference-level comparability remain pending. This portfolio project makes no claim about a merged century-long trend, changing flood frequency or the causes of observed variation.

ABOUT THIS PROJECT

The judgement behind
the chart.

A useful river-level chart depends on choices that are easy to miss: checking units, preserving station identity, examining overlapping dates and deciding how to handle questionable readings.

My focus is to make those choices visible alongside the results, so a reader can follow how the analysis was produced.
