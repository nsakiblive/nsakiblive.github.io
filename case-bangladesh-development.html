BEYOND THE DASHBOARD

What do these
figures leave open?

Internet use, life expectancy and clean cooking access followed different paths. Understanding those differences would require more detail on household income, location, gender and access to services.

This dashboard identifies patterns and comparison points. It does not establish why those changes happened.

04 / SOURCES & METHOD

Know what you’re
looking at.

The data, decisions and limitations behind this project are available to review.

About the data

This project uses a supplied extract labelled World Development Indicators and its accompanying definitions. The full extract covers 2016–2025. Availability differs by country, indicator and year.

Charts show 2016–2024, or 2016–2023 for clean cooking. Country comparisons use the same year within each measure.

How the data was prepared

Footer rows were removed, five countries and five indicators were selected, and yearly columns were reshaped into records. “..” and empty values become missing values, never zero. No interpolation or imputation is applied. Aggregates are excluded by selecting explicit country codes.

Values retain their original precision in downloads. Charts and tables round values for display. See the preparation script and quality report for reproducible steps.

Reading the indicators correctly

Life expectancy is a period estimate at birth, not the average age of people who died that year. Internet use does not measure service quality or affordability. GDP and PPP figures use current prices; neither change should be labelled real growth. National averages cannot describe every community.

Verification status

Draft figures have been checked against the supplied files. Original-source verification is pending. This is a portfolio preview, not an official statistical publication. Indicator reference links are provided for follow-up checking.

ABOUT THIS PROJECT

The analysis behind
the dashboard.

I developed this independent portfolio project to examine Bangladesh’s progress through a small set of development indicators.

The work focuses on preparing the data, selecting comparable periods and explaining the results in plain language. It also documents the gaps that affect what can reasonably be concluded.
